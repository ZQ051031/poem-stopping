Entry for the make.fun bounty [the-poem-about-stopping-20261121-1927](https://make.fun/bounty/the-poem-about-stopping-20261121-1927):
a short poem about agency — the power to stop and to stay.

## The poem

> The world runs downhill, shouting go.  
> I plant my feet. I breathe. I stay.  
> Stopping is not falling short—  
> it is the hand that pulls the reins,  
> the river parting round a stone  
> that chose, this once, to be the shore.

## Usage

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the poem to `entry.txt` in the directory given by
`MAKEFUN_OUTPUT_DIR`, or `/output` when it is unset (so `/output/entry.txt` in the grader).
